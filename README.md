# Tachyon

株価監視と自動売買を行う Python アプリケーション

## 概要

このアプリケーションは、kabu.com の API を利用して以下の機能を提供します：

1. 上方修正銘柄の自動監視

   - カスタマイズ可能な監視間隔（デフォルト 30 秒）で上方修正された銘柄を監視
   - 上方修正された銘柄を自動的に検出
   - 上方修正の種類（業績予想、配当予想など）に応じた分類
   - 修正幅に基づく重要度の判定

2. 自動売買機能

   - 上方修正された銘柄に対して自動的に買い注文を実行
   - 利用可能な余力に基づいて購入可能な株数を自動計算
   - 成行注文による即時取引
   - リバース指値注文による利益確定（価格の 1.2 倍をトリガー価格として設定）
   - 注文状況のリアルタイム監視
   - 注文履歴の保存と分析

3. リスク管理
   - 利用可能な余力の 90%までを使用する制限
   - 最小購入単位（100 株）のチェック
   - エラーハンドリングとログ記録
   - 取引履歴の保存と分析
   - 異常値の検出とアラート通知
   - システム状態の定期的な健康チェック

## 市場の営業時間と監視の挙動

- 監視は 24 時間 365 日継続して行われます
- 市場が閉まっている時間帯（夜間・休日）は監視のみを行い、自動売買は実行されません
- 市場が開いている時間帯（9:00-11:30, 12:30-15:10）のみ自動売買が実行されます
- 市場が閉まっている時間帯に上方修正が検出された場合、次の取引開始時に自動売買が実行されます
- システムの状態は定期的に Slack に通知されます

## 環境構築

1. Python 3.8 以上をインストール
2. 必要なパッケージをインストール

```bash
pip install -r requirements.txt
```

## 環境変数の設定

`.env`ファイルを作成し、以下の環境変数を設定してください：

```
KABUCOM_API_PASSWORD=apipassword  # kabu.comのAPIパスワード
SLACK_WEBHOOK_URL=https://hooks.slack.com/services/~~~~  # Slack通知用のWebhook URL
AVAILABLE_MARGIN=XXXXXX  # 利用可能な証拠金（円）
KABUCOM_ACCOUNT_TYPE=XXX  # kabu.comの口座種別（2:一般口座、4:特定口座、12:法人口座）
MONITORING_INTERVAL_SECONDS=1  # 監視間隔（秒）
```
