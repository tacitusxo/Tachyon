# Tachyon

株価監視と自動売買を行う Python アプリケーション

## 概要

このアプリケーションは、kabu.com の API を利用して以下の機能を提供します：

1. 上方修正銘柄の自動監視

   - カスタマイズ可能な監視間隔（デフォルト 30 秒）で上方修正された銘柄を監視
   - 上方修正された銘柄を自動的に検出
   - 上方修正の種類（業績予想、配当予想など）に応じた分類
   - 修正幅に基づく重要度の判定

2. 自動売買機能

   - 上方修正された銘柄に対して自動的に買い注文を実行
   - 利用可能な余力に基づいて購入可能な株数を自動計算
   - 成行注文による即時取引
   - リバース指値注文による利益確定（価格の 1.2 倍をトリガー価格として設定）
   - 注文状況のリアルタイム監視
   - 注文履歴の保存と分析

3. リスク管理
   - 利用可能な余力の 90%までを使用する制限
   - 最小購入単位（100 株）のチェック
   - エラーハンドリングとログ記録
   - 取引履歴の保存と分析
   - 異常値の検出とアラート通知
   - システム状態の定期的な健康チェック

## 環境構築

1. Python 3.8 以上をインストール
2. 必要なパッケージをインストール

```bash
pip install -r requirements.txt
```

## 環境変数の設定

`.env`ファイルを作成し、以下の環境変数を設定してください：

```
API_PASSWORD=your_api_password
AVAILABLE_MARGIN=1000000
ACCOUNT_TYPE=特定口座
MONITORING_INTERVAL_SECONDS=30  # 監視間隔（秒）
```
